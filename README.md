# Civil War — LoL 내전 기록

리그 오브 레전드 내전을 기록하고, 포지션별 활약·누적 통계·팀 추천을 제공하는 서비스다. Windows 수집기에서 가져온 경기를 참가자가 확인해 등록하고, 친구들은 공개 웹에서 전적을 조회한다.

## 시작하기

- [개발 환경 준비와 실행](docs/development/setup.md): 수집기·서버 실행, 빌드·테스트, 최초 관리자와 복구
- [현재 제품·설계 기준](docs/spec.md): 등록·권한·평가·랭킹·팀 추천의 동작
- [현재 구현·검증 상태](docs/status.md): 확인한 범위, 남은 작업과 범위 제외
- [현재 수집·API 계약](docs/contracts/api.md): 자료 정규화, 인증, 요청·응답과 오류
- [문서 안내와 정본 목록](docs/README.md): 주제별로 어디를 읽고 수정하는지 안내

각 내용은 위 정본에서 관리한다. 과거의 결정 이유·계획·검증 증거는 문서 안내에서 찾을 수 있다.
