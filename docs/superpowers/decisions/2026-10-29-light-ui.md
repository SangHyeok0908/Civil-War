# 밝은 화면과 참가자 사진 변경 결정

기록일: 2026-10-29. 사용자는 웹·Windows 수집기에 앞서 검토한 밝은 디자인을 구현하고, 아래 세부 변경과 구현 후 사용성 개선을 요청했다. 진행 중 필요한 선택은 권고 방향으로 구현하고 기록하도록 위임했다.

현재 제품 기준의 정본은 [제품 명세](../../spec.md)다. 이 문서는 당시 선택의 이유와 주체를 보존한다.

## 작업 기준과 이전 결정의 관계

기준은 `codex/participant-collector-ux`의 `9ded648`과 당시 작업 폴더의 미커밋 변경이다. 원래 작업 폴더를 수정하지 않고 새 `codex/toss-light-ui` 작업 폴더에 복사해 `6068dc3`으로 보존했다. 이 기준 커밋의 수집기 솔로랭크 제거·팀 시험과 문서는 선행 작업이며 이번 디자인의 새 구현 성과로 세지 않는다. 기존 [사용성 결정](2026-10-28-ux-requirements.md)의 자동 재개·세 경기·직접 등록 흐름을 유지한다.

## 선택 이유와 비용

프로필 사진의 목적은 같은 포지션을 가진 사람도 목록과 팀 선택에서 빠르게 구분하도록 하는 것이다. 응답 속도, 계정 식별의 정확성, 외부 장애 영향을 기준으로 방식을 비교했다.

| 선택지 | 장점 | 단점·비용 | 판단 |
| --- | --- | --- | --- |
| 화면을 열 때마다 공식 조회 | 즉시 조회한 정보를 사용 | 화면 지연과 호출 제한이 참가자 탐색에 영향 | 채택하지 않음 |
| 서버에서 번호 보관·주기 갱신 | 목록은 저장된 값을 즉시 사용, 비밀 키는 서버에 보관 | 사진 변경 반영 지연·캐시 테이블 추가 | 채택 |
| 이름 첫 글자만 표시 | 외부 의존 없음 | 요청한 실제 사진 식별을 충족하지 못함 | 장애 대체로만 채택 |

[Riot 공식 문서](https://developer.riotgames.com/docs/lol#summoner-names-to-riot-ids)에서 Riot ID의 공식 계정을 해석하고 Summoner-v4의 PUUID 조회로 소환사 자료를 얻는 경로를 확인했다. [프로필 아이콘 안내](https://developer.riotgames.com/docs/lol#data-dragon)와 같은 문서의 Profile Icons 항목에 따라 반환된 아이콘 번호를 Data Dragon 이미지에 연결한다. 사진의 자산 버전은 기존 자산 목록을 원본으로 사용한다.

사진 캐시는 참가자 ID와 조회 당시 Riot ID를 함께 보관한다. 다른 Riot ID로 편집하는 중 도착한 응답을 버리고, 이전 ID의 사진을 새 사람에게 표시하지 않는다. 실패하면 같은 ID의 마지막 정상 사진을 유지한다. 번호가 없거나 이미지 호스트가 실패하면 이름 첫 글자를 표시하며 경기 확인·저장·팀 선택을 막지 않는다. 갱신·재시도 간격은 구현 파일이 정본이다.

수집기의 좁은 창에서도 두 팀은 좌우 순서를 유지한다. 행 내부에서 이름·챔피언·K/D/A를 재배치하고 필요한 최소 폭 아래에서는 팀 영역 안의 가로 스크롤을 허용한다. 글자를 과도하게 줄이거나 레드 팀을 아래로 옮기는 대안은 사용자 요청을 충족하지 않으므로 채택하지 않는다. 실제 지원 창 크기에서 포지션 선택이 어려우면 최소 폭과 행 배치를 재검토한다.

화면의 시험 버전 문구 제거는 검증 상태가 바뀌었다는 뜻이 아니다. 현재 상태와 실제 운영·Windows·Riot 연동의 한계는 [상태 정본](../../status.md)과 이번 실행 보고서에서 구분한다.

## 구현 후 사용성 보완

실제 화면 검토에서 하단 페이지를 누르면 새 기록의 처음을 찾기 위해 다시 스크롤해야 하는 문제를 확인했다. 두 앱 모두 페이지를 넘길 때 목록 시작으로 이동하고 목록에 키보드 초점을 두도록 선택했다. 비용은 기존 버튼에 머물던 초점 위치의 변화이며, 다음 동작이 새 기록 확인이라는 점을 기준으로 판단했다. 웹 참가자의 ‘활성/비활성’도 실제 의미인 ‘팀 추천 대상/제외’로 통일했다. 과거 기록의 포함 여부나 점수 기준은 바꾸지 않는다.

추가로 폭이 작은 관리 화면에서 긴 영문 Riot ID가 잘리는 경우를 재현했다. 계정 안내 문구도 글자 단위로 줄바꿈하도록 보완했다. 긴 이름의 카드 높이는 늘어나지만 사람을 구분하는 정보와 편집 버튼을 함께 유지한다.
