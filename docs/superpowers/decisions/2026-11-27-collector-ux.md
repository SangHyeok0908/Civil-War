# 수집기 사용성 개선 결정

기록일: 2026-11-27. 수집자가 ‘롤에서 경기 가져오기’의 결과를 한눈에 읽고, 가져오는 동안의 진행 상황과 버튼을 누를 수 없는 이유를 화면에서 바로 알 수 있도록 수집기 화면을 바꿨다. 사용자가 조회 결과 문구의 가독성 문제를 직접 제기했고, 구현 담당자가 코드를 읽고 찾은 개선 후보를 사용자가 함께 진행하도록 승인했다.

현재 제품 기준의 정본은 [제품 명세](../../spec.md#가져오기-결과와-조작-안내)다. 이 문서는 당시 선택의 이유와 주체를 보존한다. 실행 결과와 한계는 [검증 보고서](../../validation/2026-11-27-collector-ux-report.md)에 둔다.

| 분류·주체 | 상태 | 지금 판단할 사항 |
| --- | --- | --- |
| 사용자 확정 · 사용자 | 조회 결과를 ` / `로 이은 한 문단 대신 읽기 쉽게 표시 | 재승인 없음 |
| 사용자 확정 · 사용자 | 구현 담당자가 제안한 열 가지를 2026-11-27 “전체 진행”으로 승인. 이 가운데 등록 확인 창은 아래와 같이 철회 | 재승인 없음 |
| 임시 선택 · 구현 담당자 | 기존 확정 요구와 충돌하는 세 가지의 범위 축소(아래 표) | 축소한 범위를 원래 제안대로 넓힐지 |
| 사용자 확정 · 사용자 | ‘내전 등록’ 앞의 확인 창을 추가하지 않음 | 재승인 없음. R06의 직접 등록 유지 |

## 문제와 변경

변경 전에는 조회 경고와 경기별 결과 문구를 중복 제거한 뒤 ` / `로 이어 경고 상자 하나에 표시했다. 경기 수가 없었고, 내전이 아니어서 제외한 정상 결과도 오류와 같은 경고로 보였으며, 모든 경기를 정상 처리하면 아무 안내도 없었다. 같은 알림 하나를 모임 연결 팝업·본문·내부 연결 실패가 함께 써서, 조회 결과가 연결 팝업에 나오거나 복구 뒤에도 문구가 남았다.

| 항목 | 변경 후 |
| --- | --- |
| 조회 결과 | 확인한 경기 수와 내전 후보·제외·문제 건수의 요약 한 문장, 사유별 건수 목록. 정상 처리만 있어도 표시 |
| 정상 제외와 문제 | 내전 형식이 아닌 경기와 등록 참가자 6명 미만 경기는 ‘제외’, 그 밖의 사유는 ‘문제’로 구분 |
| 알림 | 연결 팝업 오류·본문 오류·내부 연결 실패를 분리하고 복구하면 지움 |
| 버튼 비활성 이유 | 가져오기 버튼 아래에 이유와 필요한 행동을 표시 |
| 진행 안내 | 목록 읽기·몇 번째 경기 확인 중·서버 전송 단계를 표시. 완료 시각은 추측하지 않음 |
| 포지션 | 같은 팀에서 겹친 포지션을 해당 행에 즉시 표시 |
| 문구 | 안내 어조를 ‘~하세요’로 통일하고 문구가 없던 오류 코드에 안내를 추가. 자동 제안 표시는 R12의 용어 ‘자동 제안’으로 변경 |

‘내전 형식이 아닌 경기’는 [경기 정규화](../../../packages/lcu/src/normalize-match.ts)가 지원하지 않는 종류·형식으로 판정한 경기다. 솔로랭크처럼 사용자 설정 경기가 아닌 기록이 여기에 해당하므로 정상 제외로 분류했다. 정상 종료되지 않은 사용자 설정 경기도 같은 판정을 받아 같은 줄에 집계된다는 한계가 있다.

## 기존 확정 요구와 충돌해 범위를 줄인 항목

사용자가 승인한 제안 가운데 세 가지는 이미 확정된 요구와 충돌했다. 확정 사항을 묻지 않고 뒤집지 않기 위해 충돌하지 않는 부분만 구현했다.

| 제안 | 충돌한 확정 요구 | 구현한 범위 | 감수한 불이익 |
| --- | --- | --- | --- |
| 확인 대기 필터를 기본 선택하거나 조치가 필요한 경기를 먼저 정렬 | R25(처음에는 전체 선택), R26(시작 시각순 정렬) | 0건 필터를 흐리게 표시하고 조회 결과에 ‘확인 대기 N경기 보기’를 추가 | 확인할 경기를 보려면 한 번 더 눌러야 함 |
| ‘확인할 경기 불러오기’를 보조 ‘새로고침’으로 낮춤 | R27(버튼 이름 확정) | 이름은 유지하고 도움말을 짧게 고쳐 차이를 설명. 실행 중인 버튼에만 진행 문구 표시 | 버튼 두 개가 같은 크기로 남음 |
| 포지션 오류를 팝업 대신 행에 표시 | R06(팝업으로 수정 안내, 상시 안내 문구 제거) | 팝업은 유지하고 행 표시를 추가. 미선택 표시는 등록을 누른 뒤부터 | 팝업을 닫는 조작이 남음 |

‘내전 등록’ 앞의 확인 창은 R06의 직접 등록과 2026-10-28의 [등록 간소화 요구](2026-10-28-ux-requirements.md#수집기-사용-간소화-추가-요구)를 되돌리는 변경이어서 구현하지 않았다. 확인 창은 잘못 누른 등록을 막지만 등록마다 조작이 한 번 늘어난다. 사용자는 이 비교를 듣고 2026-11-27에 확인 창을 추가하지 않기로 정했다. 포지션 미선택·중복은 등록 전에 막으므로 직접 등록을 유지한다.

## 구현 중 정한 세부 사항

- 진행 상황은 내부 처리 영역이 화면으로 보내는 단방향 알림으로 전달한다. 화면이 주기적으로 묻는 방식은 조회마다 계정 확인과 저장소 읽기가 반복되어 선택하지 않았다. 알림에는 단계와 경기 순번만 담는다.
- 조회 결과 요약은 사용자가 닫거나 다음 조회를 시작할 때까지 유지한다.
- 경기 일시는 초를 빼고 표시한다.

재검토 조건: 정상 제외와 문제의 구분이 실제 사용에서 오해를 만들거나, 지원하는 경기 형식이 늘어나면 분류를 다시 정한다.
