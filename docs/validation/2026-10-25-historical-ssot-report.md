# 과거 기록 SSoT 정리 검증 — 2026-10-25

> **기록일 2026-10-25.** 현재 작성·보존 절차는 [정본](../../AGENTS.md#과거-기록의-보존-구역)을 따른다.

기존 과거 문서 20개에서 공통 규칙·실행법·최신 상태의 반복 설명을 정본 링크로 바꾸고, 당시 결정·측정값·검증 근거를 남겼다. 과거 기록 전체를 중복 검사에서 제외하던 처리를 없앴다. 이 보고서의 수치와 결과는 2026-10-25 편집·검사에 관한 기록이다.

## 결정과 편집 범위

| 분류 | 주체·상태 | 적용 |
| --- | --- | --- |
| 사용자 확정 | 사용자, 2026-10-25 직접 요청 | 과거 기록도 SSoT(단일 정본) 방식으로 정리하되 당시 결정·측정·검증 근거는 보존 |
| 위임받은 선택 | 구현 담당자, 적용·로컬 검증 완료 | 고정 근거에만 내용 해시를 등록해 중복 예외를 제한. 공통 설명을 구역으로 감싸 검사에서 숨기지 않음 |

과거 기획·개발 계획·단계 계약은 규칙 표와 공통 명령을 현재 명세·계약·개발 안내로 연결했다. 초기 제안과 사용자 확정을 구분했고, 목표물 지표의 이전 혼합안과 이후 선택을 같은 기준으로 덮어쓰지 않았다. 결정 기록에는 선택 이유·대안·제약·재검토 조건과 고유한 당시 판단을 남겼다.

검증 보고서에는 실행 환경·시험 표·실패·제한·원본 경로·화면·해시를 남겼다. 미실행 Windows 수용 계획은 실행 성공으로 바꾸지 않고 당시 계획으로 표시했다. 2026-10-24 SSoT 보고서의 24개 검사와 당시 한계도 그 날짜의 결과로 보존했다. 현재 링크가 당시 값과 동일하다는 의미가 아님을 편집 주석에 표시했다.

## 보존 대조

- 기존 20개 문서의 제목과 순서를 수정 전 사본과 대조했다. 기존 연결에 쓰는 명시적 앵커도 유지했다.
- T01–T12의 테스트·수용 검증 24개 행, T13·T14 전체, 재검증 도구의 실행 기록과 가독성 검증 결과는 당시 원문과 대조해 보존했다.
- 실제 관측 근거인 시험 수·런타임 버전, G1 화면 대조 150개, 원본 통계 660개·비식별 값 1,639개·비교표 90행, LCU 참가자 30행·공식 API 참가자 60행 분석, 공식 API 6경기의 표·접근 실패를 확인했다. 실제 관측과 합성 자료·미실행 조건의 경계를 유지했다.
- 예외는 4개 구역의 본문 8줄로 한정했다. 권한 승인·검증 제외 지시·사용자 확정 원문과 특정 원본 감사 명령이며, 모든 구역이 이번 편집 전 원문에 존재하고 등록 해시와 같음을 확인했다. 상세 목록은 [생성된 보존 목록](../README.md#보존한-과거-기록-구간)을 따른다.
- 편집 대상 20개의 줄 수는 3,214줄에서 2,660줄로 줄었다. 이 값은 줄바꿈·표식·주석을 포함한 파일 줄 수이며 제거한 규칙이나 사실의 개수가 아니다. 새 보고서는 이 비교에서 제외했다.

제품 코드·계산 버전·기존 스키마·시험 자료는 이번 작업에서 바꾸지 않았다. 기존 두 JSON Schema 파일은 Git에 저장된 내용과 바이트가 같음을 확인했다.

과거 문서의 미표시 복사 본문, 보존 구역 밖의 복사, 해시 변경, 미등록·미사용·중첩·닫히지 않은 표식, 정본·참조 문서의 예외 시도, 보존 구역 안의 깨진 링크를 테스트했다. 처음 실패를 확인한 뒤 수정했고, 잘못된 표식 때문에 나머지 본문이 검사에서 빠지는 경우도 거절한다. 독립 검토에서 Git 탐색에 잡히지 않는 등록 문서의 우회를 발견해 실패를 재현한 뒤 등록부 경로까지 합쳐 검사하도록 고쳤다.

최신 표식 문법과 등록 절차는 AGENTS.md를 따르며 이 실행 기록에 별도 규약을 복사하지 않는다.
