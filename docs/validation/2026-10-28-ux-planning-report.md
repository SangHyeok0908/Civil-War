# 사용자 경험 요구사항·구현 계획 문서 검토

기록일: 2026-10-28. 편집·보완일: 2026-10-28. 현재 구현·검증 상태는 [상태 정본](../status.md)을 따른다.

## 범위와 환경

macOS의 현재 저장소에서 사용자 대화, [제품 정본](../spec.md), Java 서버·Electron 수집기·웹 화면·DB 전환 파일을 대조했다. 이번 산출물은 요구사항 정리·결정 근거·구현 계획이며 실행 제품의 수정이나 테스트가 아니다. 실제 Riot API 요청·게임 클라이언트 조회·Windows 설치·운영 DB 변경은 수행하지 않았다.

## 요구사항과 계획 대조

R01–R27의 입력·게스트·인증·역할·챔피언·표시 축소·진행·목록·문구를 [작업 추적표](../superpowers/plans/2026-10-28-ux-improvements.md#요구사항-추적표)와 연결했다. 사용자 선택과 P01–P07의 기술 제안, 현재 계약과 구현 목표의 차이를 분리했다. 최신 상태 문서에 있던 Windows 시험 제외와 후속 설치 결과를 보존했다.

독립 문서 검토자는 누적 평균의 게스트 포함 여부가 정본과 P02에서 다르다고 지적했다. 현재 회원으로 연결된 기록을 평균에 포함하고 정식 전환 시 다시 계산한다는 제안으로 두 문서를 맞췄다. 그 밖의 중요한 미해결 질문은 없다는 검토 결과를 받았다. 계정 연결 조사는 검증 전제이며 이미 성공한 구현으로 취급하지 않았다.

## 자동 문서 검사

저장소가 요구하는 Node.js 24.22.1과 pnpm 11.5.0으로 다음을 실행했다. 처음 시스템 Node.js 23으로 실행한 결과는 최종 근거에서 제외하고 지정 버전으로 다시 확인했다.

| 검사 | 결과·무엇을 확인한 값인가 |
| --- | --- |
| `pnpm docs:index` | 등록부에서 안내표 생성. 생성 후 미갱신 차이 없음 |
| `pnpm test:docs` | 문서 검사기 회귀 사례 66개 통과, 실패·건너뜀 0개 |
| `pnpm docs:check` | 등록·정본·내부 링크·중복 문단·생성 안내표 검사 통과 |
| `git diff --check` | 변경 파일의 공백 오류 없음 |
| 요구사항 번호 대조 | 정본의 R01–R27이 각각 한 번 존재하고 누락 없음. 계획의 T01–T11과 연결 |

이 검사는 제품 기능·Riot 연결·실제 Windows 동작을 검증하지 않는다. 의미 중복은 새 정본·결정 기록·계획·현행 계약을 수동 대조했으며, 새 상세 규칙은 정본에서 관리하고 계획은 작업·증거를 연결한다.

## 남는 미확인

계정 자동 연결 경로, 등급 실시간 조회, 환산 정책의 모임 내 균형, 포지션 제안 정확성은 제품 구현 과정에서 확인해야 한다. 이번 보고서의 문서 검토 성공을 이 기능들의 성공 근거로 사용하지 않는다. 별도 구현·배포는 이번 작성 범위에 포함하지 않았다.
