# Windows 추가 경기 검증 절차 — 철회

> **과거 기록 · 2026-10-23.** 현재 기준은 [정본](../status.md)을 따른다.

> **2026-10-25 편집 보완:** 반복 설명을 정본 링크로 줄였다. 사건 날짜·실측값은 당시 기록이며 현재 링크로 갱신하지 않았다.

2026-10-23 사용자 결정으로 이 문서의 실행 절차를 제거했다. 다음 항목은 남은 작업·보류 사유·완료 조건에 포함하지 않는다.

- 경기 중 도구를 실행하지 않은 첫 경기의 종료 후 조회(C01).
- 다음 경기 전에 도구를 켜 두고, 종료 후 새 프로세스의 조회와 비교하는 검증(C02).
- 경기 종료 후 반영 시간과 과거 조회 범위 측정(C10).
- 실제 3–5경기 시범 운영(T15).

기존 실측 자료는 보존하며 제외한 항목을 검증 성공으로 기록하지 않는다. 새 내전·추가 페이지 조회·시간별 재조회 자료를 요구하지 않는다.

2026-10-23 철회 당시에는 피해 의미·점수 기준, Windows 설치·업데이트, 서버 외부 접속·백업·복원을 후속 범위로 남겼다. 이후 C07 조사 이력은 [의미 감사](lcu-objective-semantics.md#이전-판정-이력), 현재 남은 작업은 [진행 상태](../status.md#남은-작업-순서)에 있다. 당시 T13–T14 계획의 출처는 [2026-10-21 서비스 개발 계획](../superpowers/plans/2026-10-21-lol-inhouse-development-plan.md)이다.
