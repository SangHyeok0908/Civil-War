# Stage 3 HTTP/JSON contract — provisional

> 기록일 2026-10-22. 현재: [API 정본](api.md).

> 2026-10-25: 반복 설명을 정본 링크로 정리했다. 날짜별 사실·근거는 보존하며, 현재 링크의 값은 당시와 다를 수 있다.

2026-10-22 단계 3은 [1단계 기록](stage1-api.md)의 인증·회원·등록 흐름 위에 평가 세대, 누적 통계, 팀 추천과 관리 화면을 더했다. 자료 구조의 원본은 [stage3.schema.json](stage3.schema.json)이며 1단계 당시 평가 미구현 상태는 [stage1.schema.json](stage1.schema.json)에 남아 있다.

당시 추가한 공개 점수·세대 조회는 [점수·순위와 팀 추천](api.md#점수순위와-팀-추천), 규칙 버전·재계산 작업은 [계산 규칙 검증·게시·복구](api.md#계산-규칙-검증게시복구), 공식 계정의 별도 연결은 [공식 기록 참고 자료](api.md#공식-기록-참고-자료-가져오기)를 참조한다. 경로 표·상수·계산식은 여기서 다시 관리하지 않는다.

**1단계 대비 보완:** 공개 경기의 `generationId`·`scores`를 추가하고 점수가 없어도 기록 조회는 HTTP 200으로 유지했다. 관리자 원본 화면에는 큰 숫자를 보존하는 `rawJson`을 추가했다. 코드 메타데이터와 감사 조회, Data Dragon 이미지 및 같은 JAR의 정적 화면도 이 단계에 연결했다. 현재 반환 형식은 각각 [공개 기록](api.md#공개-기록과-관리자-정정), [인증](api.md#인증과-권한), [정적 화면](api.md#정적-화면과-이미지)에 있다.

**2026-10-24 보완 당시의 차이:** 구현 식별자는 `objective-provisional-v1`이었다. [D04](../superpowers/decisions/2026-10-22-overnight-decisions.md#d04--c07-hold와-중복-가중을-피하는-잠정-정책)의 임시 단일 피해 지표와, 포함 관계 조사 뒤 사용자가 선택한 [D24](../superpowers/decisions/2026-10-22-overnight-decisions.md#d24--2026-10-24-목표물-공격-평가-기준-사용자-확정)는 결정 상태가 달랐다. 선택을 마쳤어도 새 계산 버전·계약/화면 설명·전 경기 재계산과 검증은 아직 남았다. 당시 의미 근거는 [목표물 조사](../validation/lcu-objective-semantics.md), 최신 반영 상태는 [진행 상태](../status.md)에 둔다.

단계 3의 실제 검증 환경·실행 수·한계는 [3단계 보고서](../validation/stage3-report.md)를 따른다. 당시 실시간 수집기 참고 내보내기는 `OFFICIAL_API_UNAVAILABLE`이었으며 공식 포털의 조회 성공을 제품 연동 완료로 바꾸지 않았다. 현재 제한은 [범위 제외와 미확인 사실](../status.md#범위-제외와-미확인-사실)을 확인한다.
